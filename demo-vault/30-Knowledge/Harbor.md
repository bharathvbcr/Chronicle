# Harbor

_Local-first note capture_

Harbor writes every capture straight to plain Markdown in a synced folder. No account, no server.

- Capture lands in `_capture/entries/` as JSON, then gets folded into `notes/daily/`.
- The folder contract is the API: anything that can read Markdown can read the vault.
